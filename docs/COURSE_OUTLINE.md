# 课程包总览

1. 企业级 AI 数据分析平台与制造供应链领域建模。
2. FastAPI 模块化单体、PostgreSQL RLS 与 JWT/OIDC 边界。
3. 只读数据源、Schema 同步、SQL AST 安全校验和审计。
4. RAG 指标口径、MCP 工具契约与多 Agent 编排。
5. Celery 任务、Redis 记忆、OpenTelemetry 与故障恢复。
6. React 数据分析控制台、ECharts 图表和供应链大屏。
7. Docker Compose、Helm、CI/CD 与企业交付答辩。

每章包含起始代码、完成代码、练习、验收条件和常见故障排查。详见项目 README 的运行说明。
